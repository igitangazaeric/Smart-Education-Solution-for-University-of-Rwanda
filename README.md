Upgrading of Teaching, Learning Facilities and ICT Enables Pedagogies at University of Rwanda: Design, Supply, Installation of Smart classrooms and Smart Laboratories, Virtual Laboratories and Provide ICT Skills and Innovative pedagogical Training
Project Overview
This repository documents my contribution as an Individual Consultant in the successful implementation of the Upgrading of Teaching, Learning Facilities and ICT-Enabled Pedagogies Project at the University of Rwanda. The project involved the design, configuration, integration, testing, and documentation of Smart Classrooms, Smart Laboratories, Virtual Laboratories, and supporting ICT infrastructure. 
Consultant: Eric IGITANGAZA
Project Duration: April – September 2026
Key Responsibilities
1. Smart Classroom & Laboratory Systems Configuration
•	Configured and commissioned Smart Classroom environments.
•	Integrated Smart Laboratory and Simulation Room technologies.
•	Conducted system testing and validation to ensure operational readiness.
•	Supported ICT-enabled teaching and learning environments. 

2. Network Infrastructure Deployment
•	Configured enterprise network switches, routers and firewalls.
•	Configured wireless LAN infrastructure.
•	Configured wireless controllers and access points.
•	Implemented connectivity for Smart Classrooms and Laboratories.
•	Verified network performance and service availability. 

3. Network Management System (NMS)
•	Installed and activated the Network Management System.
•	Integrated network devices with centralized monitoring.
•	Validated monitoring, alerting, and performance reporting capabilities.
•	Supported operational visibility and proactive fault management. 

4. Backup and Recovery Implementation
•	Established system backup procedures.
•	Configured backup policies for critical systems and configurations.
•	Verified restoration procedures to support business continuity.
•	Ensured operational resilience of deployed solutions. 

5. Technical Documentation
•	Developed As-Built Documentation.
•	Prepared infrastructure configuration records.
•	Documented deployed network and system architecture.
•	Produced operational handover documentation for future support and maintenance.
